# CNC Programming Using CAM Package for Turning of Rolls on CNC Lathe

## Internship / Project Work

This repository documents my internship/project work carried out at **Rashtriya Ispat Nigam Limited (RINL) – Visakhapatnam Steel Plant**.

The project focused on **CNC programming using a CAM package for turning of rolls on a CNC lathe**, providing practical exposure to computer-aided manufacturing and industrial machining processes.

---

## 📌 Project Overview

The project involved understanding the use of **CAM-based CNC programming** for machining rolls on a CNC lathe.

The work focused on developing an understanding of the workflow involved in converting machining requirements into CNC programs for industrial turning operations.

---

## 🎯 Project Objectives

- Understand CNC lathe operations.
- Study CNC programming for roll turning.
- Understand the application of CAM software in manufacturing.
- Generate appropriate tool paths for CNC machining.
- Understand the workflow from component geometry to CNC machining.
- Gain practical exposure to industrial machining processes.
